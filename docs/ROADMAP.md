# Роадмап

Иди сверху вниз. Закончил пункт (проверки зелёные, коммит запушен) — поставь `[x]` и добавь
строку в «Журнал». Этапы упорядочены так, чтобы оборванная на любом месте сессия оставила
рабочий сайт.

## Этап 0. Каркас
- [ ] `web/`: Next.js (App Router, TS strict, ESLint), pnpm; скрипты `lint`, `typecheck`, `test` (Vitest), `build`
- [ ] `chat/`: Poetry-проект, aiohttp-приложение с `GET /chat/health`, ruff, pyright, pytest
- [ ] `.github/workflows/ci.yml`: проверки обеих частей на push и PR
- [ ] `README.md` проекта: что это, как запустить обе части локально

## Этап 1. Дизайн-система и темы
- [ ] Токены (цвета, типографика, радиусы, тени, анимации) для тем «Человек» и «Гуль» в одном файле
- [ ] Переключатель-глаз: анимация пробуждения какугана, `localStorage` + `prefers-color-scheme`, без мигания при загрузке
- [ ] Базовые компоненты: пузырь сообщения, пост канала, шапка диалога, поле ввода, аватар-заглушка (свой SVG)

## Этап 2. Оболочка «Telegram-клиент»
- [ ] Двухколоночный лейаут: список диалогов + открытый диалог; маршруты `/c/<id>`, `/` открывает Self
- [ ] Мобильный режим: список ↔ диалог, «назад», жесты не обязательны
- [ ] Список диалогов: аватар, название, последнее сообщение, время, закреп, счётчик «непрочитанного» для Live-чата
- [ ] Скриншоты 1440px и 390px в обеих темах просмотрены, баги поправлены

## Этап 3. Контент
- [ ] Данные из `docs/CONTENT.md` → типизированные объекты в `web/src/content/`
- [ ] Диалог **Self**: профиль, «био», стек по группам, контакты, цитата
- [ ] Канал **Проекты**: посты с рангом CCG; пост раскрывается в подробности (стек, ссылки, цифры); фильтр по рангу
- [ ] Схема экосистемы chestor.site (SVG, адаптивная, в обеих темах)
- [ ] Хронология (как посты с датами или отдельный пост)

## Этап 4. `/bot`
- [ ] Лендинг chestor_bot: лор и механики (голод, кагуне, бои, экономика), формат «досье CCG» или своё
- [ ] Команды и примеры диалогов с ботом в виде Telegram-переписки
- [ ] Цифры и стек, ссылка на репозиторий
- [ ] Диалог **@chestor_bot** в оболочке: пара шуточных ответов на ввод + ссылка на `/bot`

## Этап 5. `/selfrotgram`
- [ ] Лендинг: «типы говорят правду», пример Echo с подсветкой, что гарантирует фильтр
- [ ] Было (aiogram) / стало (selfrot) — 3–5 пар из `docs/from-aiogram.md` фреймворка
- [ ] Демо-терминал: анимированный `selfrot tree` / `selfrot check`
- [ ] Установка, ссылки на PyPI и GitHub; канал **selfrotgram** в оболочке ведёт сюда

## Этап 6. Сервис чата (`chat/`)
- [ ] Хранилище (память / Redis), модель сообщения, история, WebSocket-рассылка
- [ ] `CHAT_MODE=mock`: фейковый собеседник для UI
- [ ] Капча на Ghoul Quiz (гостевой вопрос + проверка; фикстура без сессии), подписанный пропуск
- [ ] `POST /chat/send`: валидация ника и текста, лимиты, очередь в группу ≤ 15/мин
- [ ] `CHAT_MODE=telegram`: бот на selfrotgram — сообщения группы → WS, сайт → группа (`entities`, без `parse_mode`)
- [ ] Модерация: `/ban`, `/unban` ответом, `/mute_site <минуты>`
- [ ] Тесты: лимиты, капча, бан, отказ форматирования, очередь, фейковый Telegram
- [ ] `selfrot check --strict` по диспетчеру бота

## Этап 7. Live-чат и CCG Checkpoint в интерфейсе
- [ ] Диалог **Live-чат**: история, WS с переподключением, онлайн, выбор ника, отправка, ошибки лимитов в тему

- [ ] Пасхалка `1000-7`, `/start` в диалоге бота
